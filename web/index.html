BF16 → INT8 pin

Download the dense checkpoint. Convert once. Default dest is INT8. Use NF4 only when you need to fit. GGUF / GPTQ / Unsloth-4bit are not sources.

Already-quantized NF4 is refused unless --allow-requant. Ampere still GEMMs in f16/f32.

Command

python3 bf16_to_int8.py pin \
  --src /path/to/bf16-model \
  --out /path/to/int8-pin \
  --to int8
# hangover CLI name (same entry):
python3 nf4_to_int8.py pin --src /path/to/bf16-model --out /path/to/int8-pin --to int8
# fit:
python3 nf4_to_int8.py pin --src /path/to/bf16-model --out /path/to/nf4-pin --to nf4

What it writes

  1. *.weight I8 [out, in]
  2. *.weight.int8_scale F32, amax/127 per block
  3. *.weight.int8_state JSON
  4. BF16 embed / norms / skipped MLPs copied
  5. pin.json + RMSE vs NF4 dequant
